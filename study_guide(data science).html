Core Concepts & Learning Content

🐍 Python Programming and Data Science Libraries ▼

Concept Explanation:

Python is the most widely used language in data science due to its readable syntax and powerful libraries. Key libraries include NumPy (numerical arrays), pandas (data manipulation), Matplotlib/Seaborn (visualization), and scikit-learn (machine learning).

Key Formulas & Rules:

  • np.array() creates arrays
  • reshape() changes dimensions
  • Slicing syntax: array[row_start:row_end, col_start:col_end]
  • Vectorized operations replace explicit loops for speed

Tricky Points:

Understanding zero-based indexing, multidimensional slicing, difference between lists and arrays in memory footprint, and homogeneous data types in arrays.

📊 Descriptive and Inferential Statistics ▼

Concept Explanation:

Descriptive statistics summarize data (mean, median, variance). Inferential statistics use samples to make population generalizations through hypothesis testing and confidence intervals.

Key Formulas:

  • Mean: x̄ = (1/n) Σ xᵢ
  • Variance: σ² = (1/n) Σ (xᵢ - x̄)²
  • Standard deviation: σ = √σ²
  • Z-score: z = (x - μ)/σ
  • Bayes' theorem: P(A|B) = P(B|A) × P(A) / P(B)

Tricky Points:

Difference between population and sample statistics, p-value interpretation, correlation vs causation, handling skewness and kurtosis.

🤖 Core Machine Learning Algorithms ▼

Concept Explanation:

Machine learning builds predictive models from data. Supervised learning uses labeled data for regression and classification. Unsupervised learning finds structure without labels.

Key Formulas:

  • Linear regression: y = β₀ + β₁x₁ + ... + βₙxₙ + ε
  • Logistic sigmoid: σ(x) = 1/(1 + e⁻ˣ)
  • Mean Square Error (MSE) for regression
  • Cross-Entropy for classification

Tricky Points:

Avoiding overfitting with regularization (L1/L2), selecting right algorithms, understanding evaluation metrics (accuracy, precision, recall, ROC AUC).

🧹 Data Preprocessing & Cleaning ▼

Concept Explanation:

Real-world data is messy. Preprocessing involves cleaning by handling missing values, encoding categorical variables, scaling features, and detecting outliers.

Key Techniques:

  • Mean imputation: x_missing = (1/n) Σ xᵢ
  • Standardization: x_scaled = (x - μ)/σ
  • One-hot encoding for categorical variables
  • Outlier detection using IQR or Z-score

Quick Reference Guide

🔤 Key Python Functions

  • pd.read_csv() - Load data
  • df.groupby() - Group operations
  • np.mean() - Calculate mean
  • sklearn.model_selection - Split data

📊 Statistical Tests

  • t-test - Compare means
  • Chi-square - Test independence
  • ANOVA - Multiple group comparison
  • Correlation - Measure relationship

🤖 ML Evaluation Metrics

  • Accuracy = (TP + TN) / Total
  • Precision = TP / (TP + FP)
  • Recall = TP / (TP + FN)
  • F1 = 2 × (Precision × Recall) / (Precision + Recall)

🎨 Visualization Types

  • Histogram - Distribution
  • Scatter - Correlation
  • Box plot - Outliers
  • Bar chart - Categories
